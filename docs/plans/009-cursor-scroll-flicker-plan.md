# カーソル移動時の現在セクションちらつき修正

## 目的

Vim プラグインの `j` による連続移動中、自動スクロールで
現在セクションが一瞬上のセクションへ戻る現象を解消する。

## 原因

カーソル移動時はカーソル行、スクロール時は表示領域上端の行から
現在セクションを更新するため、両イベントが連続すると表示が競合する。
既存の 100 ms のスクロール抑止は見出しジャンプだけが対象になっている。
イベント順序の模擬では再現済み。実機での再現確認は未実施。

## 修正方針

1. カーソル位置変更を検出した時刻を保持する。
2. 通常のカーソル移動から 100 ms 以内もスクロール更新を抑止する。
3. 既存の見出しジャンプ直後の抑止と 16 ms のスロットリングを維持する。
4. 100 ms 経過後の手動スクロールは従来どおり表示位置に追従させる。
5. 新しいタイマーやイベントリスナーは追加しない。
6. カーソル移動とスクロールが競合した際の優先順位を仕様に追記する。

## 検証

- カーソル移動直後のスクロールで現在セクションが上書きされないこと。
- 100 ms の境界、連続移動での時刻更新、見出しジャンプをテストする。
- `npm test`、`npm run build`、`git diff --check` を実行する。
- 実機で対象ノートの `j`・`k` 連続移動、手動スクロール、
  見出しジャンプ、見出しクリック、プレビュー同期を確認する。

## 実施結果

- 通常のカーソル位置変更でも時刻を記録し、100 ms 未満のスクロール更新を抑止した。
- 見出しジャンプの抑止と既存のスロットリングを維持した。
- 通常移動・連続移動それぞれの 99 ms と 100 ms の境界テストを追加した。
- 現在見出しの優先順位を仕様に追記した。
- `npm test` は 52 件成功。`npm run build` と `git diff --check` は成功。
- `lib/` は既存の Git 除外設定に従い、ビルド生成のみ行った。
- 実機での動作確認は未実施。
