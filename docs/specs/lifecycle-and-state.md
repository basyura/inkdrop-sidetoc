# ライフサイクルと状態管理

## 有効化

プラグイン有効化時に以下を行う。

1. `SideTocPane` React コンポーネントを Inkdrop へ登録する。
2. `mde` レイアウトの `Editor` 直後へコンポーネントを挿入する。
3. ペインへ `Activate` アクションを送信する。
4. SideTOC の 7 コマンドを `document.body` へ登録する。

`Activate` 受信時は、表示状態を `defaultVisible` に設定し、アクティブエディターとの
接続を試行する。

## 無効化

プラグイン無効化時に以下を行う。

1. ペインへ `Deactivate` アクションを送信し、非表示にする。
2. 登録したコマンドを破棄する。
3. レイアウトから `SideTocPane` を削除する。
4. 登録したコンポーネントクラスを削除する。

コンポーネント破棄時には Dispatcher、タイマー、Inkdrop のエディター購読、
DOM イベント、各 Observer を解除する。

## エディター接続

アクティブエディターが利用可能になった場合に、以下を接続する。

- エディターの `dispatch` をラップした文書変更および選択変更の検出
- 編集領域のスクロールイベント
- プレビュー領域のスクロールイベント
- プレビュー DOM の `MutationObserver`
- `document.body` 属性の `MutationObserver`
- SideTOC ペインの `ResizeObserver`

エディターがまだ利用できない場合は 100 ms 間隔で再接続を試行する。
試行上限は 100 回である。接続済みの同一エディターに対しては重複接続しない。

## ノート切り替え

`editingNote._id` の変更を検出すると、以下を行う。

- DOM 要素キャッシュと既存のイベント接続を破棄する。
- プレビュー見出し、現在位置、初回スクロール状態を初期化する。
- 新しいノート本文を解析し、目次を更新する。
- アクティブエディターへ再接続する。

## React 状態

| 状態 | 内容 |
| --- | --- |
| `visibility` | 利用者が切り替えるペインの表示状態 |
| `headers` | Markdown 本文から抽出した見出し一覧 |
| `currentHeader` | 編集モードで現在位置に対応する見出し |
| `min` | 抽出された見出しの最小レベル |
| `len` | エディター文書の行数 |

## 内部状態

React の描画状態とは別に、以下を保持する。

- 現在接続中のエディターとノート ID
- プレビューモードかどうか
- プレビュー DOM から取得した見出し要素と現在位置キー
- 再接続タイマーと試行回数
- イベント購読、DOM 要素、Observer
- 描画結果、目次項目スタイル、DOM 要素のキャッシュ

描画結果は見出し一覧、表示状態、現在見出しのいずれかが変化した場合に破棄する。
スタイルキャッシュは見出し一覧、現在見出し、最小見出しレベルが変化した場合に
破棄し、保持件数が 100 件を超えた場合は最初に登録された項目を削除する。

## Dispatcher

プラグイン入口とペイン間の操作通知には Flux Dispatcher を使用する。
ペインはマウント前にコールバックを登録し、アンマウント時に解除する。
コマンドごとのアクションはペイン内のハンドラーへ変換される。

## エラー時の挙動

- アクティブエディターがない場合は目次更新や移動を行わない。
- エディターが必要なインターフェースを持たない場合は接続を延期する。
- 対応する見出しがない場合、クリックや前後移動では位置を変更しない。
- 利用者向けのエラー通知やログ出力は行わない。
