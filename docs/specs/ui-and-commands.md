# 表示とコマンド

## SideTOC ペイン

### 表示条件

以下をすべて満たす場合にペインを表示する。

1. ペインの表示状態が有効である。
2. 見出しが 1 件以上存在するか、`showIfNoHeader` が有効である。

表示状態の初期値は `defaultVisible` から取得する。
表示切り替え後の状態はセッション中のコンポーネント状態であり、設定値へは保存しない。

### 目次項目

- 見出しを文書内の出現順に 1 行ずつ表示する。
- 最も浅い見出しレベルを基準に、レベル差 1 ごとに左余白を 20 px 増やす。
- 項目の行高は 180%、左側のパディングは 10 px とする。
- 通常の文字色には Inkdrop の `--editor-foreground-color` を使用する。
- 現在見出しとホバー中の項目には設定された前景色と背景色を使用する。
- 現在見出しが変わると、その項目がペイン内に入る位置まで縦スクロールする。

### 長い見出し

`textwrap` が有効な場合は、長い文字列を単語途中でも折り返す。
無効な場合は 1 行に制限し、領域外を省略記号で表示する。

### サイズ

- ペインの最小幅と最大幅を同じ値にして固定幅とする。
- ペイン内側の左右パディングは各 10 px とする。
- 目次のスクロール領域幅は、ペイン幅から左右パディングの合計 20 px を引いた値とする。
- ペインの高さが変化した場合は、目次のスクロール領域を再計算する。

## コマンド一覧

| コマンド | 挙動 |
| --- | --- |
| `sidetoc:sidetoc-toggle` | ペインの表示状態を切り替える |
| `sidetoc:jump-next` | 次の見出しへ移動する |
| `sidetoc:jump-prev` | 現在または前の見出しへ移動する |
| `sidetoc:width-increase` | ペイン幅を増やす |
| `sidetoc:width-decrease` | ペイン幅を減らす |
| `sidetoc:width-reset` | ペイン幅を設定値へ戻す |
| `sidetoc:wraptext-toggle` | 見出し文字列の折り返しを切り替える |

すべてのコマンドは `document.body` に登録する。

## メニュー

Inkdrop の `Plugins > sidetoc` 配下に以下を表示する。

- `Toggle SideToc`
- `Increase width`
- `Decrease width`
- `Reset width`

前後移動と折り返し切り替えはメニューへ登録しない。

## 既定キーバインド

`body` スコープで以下のみを登録する。

| キー | コマンド |
| --- | --- |
| `Ctrl-L` | `sidetoc:sidetoc-toggle` |

その他のコマンドには既定のキーバインドを設定しない。利用者は Inkdrop の
キーマップ設定から任意のキーを割り当てる。

## クリック操作

- 編集モードでは、クリックした見出し行へカーソルを移動し、エディターを
  スクロールしてフォーカスする。
- プレビューモードでは、対応するプレビュー見出しまでプレビューをスクロールし、
  `editor:focus` コマンドを実行する。
