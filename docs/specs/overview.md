# 概要

## 目的

SideTOC は、編集中の Markdown ノートに含まれる見出しを目次として表示し、
ノート内の現在位置の把握と見出し間の移動を支援する Inkdrop プラグインである。

## 提供機能

- Markdown 見出しを SideTOC ペインへ文書順に表示する。
- 見出しレベルに応じて項目を字下げする。
- 編集位置またはプレビューの表示位置に対応する項目を強調表示する。
- 目次項目のクリックにより、対応する見出しへ移動する。
- コマンドにより、前後の見出しへ移動する。
- ペインの表示、非表示を切り替える。
- ペイン幅の拡大、縮小、リセットを行う。
- 長い見出しの折り返し表示を切り替える。
- テーマ変更時に強調色を再取得する。

## 配置

プラグイン有効化時に、`mde` レイアウトの `Editor` コンポーネント直後へ
`SideTocPane` を挿入する。このため、SideTOC ペインはエディターの右側に配置される。

## 表示対象

目次の抽出元は、アクティブエディターの Markdown 文書である。
ノートを切り替えた場合は、新しいノートの内容から目次を再作成する。

## 対象外

- Setext 形式の見出し
- HTML 要素として記述された見出し
- フェンス内に記述された見出し
- ノートをまたぐ目次
- 見出しの編集、追加、削除を目次側から行う機能
- 目次階層の折り畳み

## 実装上の前提

- Inkdrop 6 のエディターが `state.doc`、`dispatch`、`scrollDOM` などの
  CodeMirror 6 相当の参照を提供することを前提とする。
- UI 要素の検出には Inkdrop の DOM クラス名を使用する。
- プレビュー内の見出し順序と Markdown から抽出した見出し順序が一致することを
  前提として、両者を添字で対応付ける。
